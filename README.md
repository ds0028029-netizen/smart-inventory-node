# Smart Inventory Management System

A Node.js-based application to manage products, track stock levels, and monitor inventory efficiently.

## Features
- Product management
- Inventory tracking
- Stock monitoring
- Efficient inventory management

## Installation

1. Download and extract the project ZIP file.
2. Open the project folder in VS Code.
3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

5. Open the local URL configured in the project.

## Technologies
- Node.js
- JavaScript
- npm
